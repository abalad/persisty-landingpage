The queue and restore points live in the **bar on the session's right edge** (**Request queue** and **Restore points**). The own folder is chosen in **New session**, and check on finish in the workspace command menu, to the right of the tabs. The Pro features require a Persisty account on the Pro plan; what has already been saved stays usable if the plan ends. Claude accounts, with rotation, switching from the footer and an account per project, are in [AI accounts and rotation](/docs/ai-accounts).

## Request queue

Write the agent's next requests now and choose when each one goes; see [Request queue](/docs/queue).

## Restore points

Each request to an agent saves the folder's state before it starts, so you can go back; see [Restore points](/docs/restore-points).

## Check on finish

A workspace command, such as the tests, runs on its own when the agent stops after changing files; see [Check on finish](/docs/verify).

## Own folder per session

The session gets a branch in a folder of its own, so two agents never edit the same files; see [Own folder](/docs/worktrees).
