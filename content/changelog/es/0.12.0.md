title: Archivos en el árbol, como en un IDE

El árbol de archivos del editor ahora hace lo que se espera de un IDE: renombrar, mover, copiar, pegar y eliminar, con el teclado, el menú y arrastrando.

### Añadido

- **Renombrar archivos y carpetas desde el árbol y desde la pestaña (Shift + F6).** El nombre se edita en la misma fila, y las pestañas abiertas siguen al archivo con el texto sin guardar y el deshacer.
- **Mover y copiar a otra carpeta (F6 y F5).** Una lista con búsqueda elige la carpeta. Al copiar un solo elemento, se le puede cambiar el nombre ahí mismo. Los tres están también en el submenú Refactorizar.
- **Arrastrar en el árbol para mover.** Basta con sostener el archivo o la carpeta y soltarlo sobre otra carpeta. Con Option (Alt en Windows y Linux), copia.
- **Cortar, copiar y pegar archivos y carpetas en el árbol** (Command + X, C y V en el Mac; Control + X, C y V en Windows y Linux). También se puede pegar lo que se copió en el Finder, en el Explorador de archivos de Windows o en el gestor de archivos de Linux, y al revés.
- **Eliminar a la Papelera, con Deshacer.** Delete o Command + Backspace en el Mac, y Delete en Windows y Linux. Siempre pide confirmación, y durante 10 segundos se puede deshacer desde el aviso o con Command + Z (Control + Z en Windows y Linux).
- **Una sola pregunta cuando el nombre ya existe.** Renombrar, reemplazar (el anterior va a la Papelera) u omitir, con "hacer lo mismo con los siguientes". Antes de reemplazar un archivo con cambios sin guardar, Persisty pregunta.
- **Las copias grandes muestran el avance y se pueden cancelar.** Cancelar no deja nada a medias en el destino.
- **Cambiar el tipo de un archivo**, por ejemplo un `.env` como Shell, desde el árbol, la pestaña o la paleta de comandos (Command + K). La elección vale para la carpeta del proyecto y sigue al archivo cuando se mueve.
- **Si mover o copiar se detiene a mitad, lo que ya pasó se queda**, y Persisty dice qué elemento falló.

En Windows y Linux, pegar archivos con el sistema y el Deshacer tras eliminar todavía se están comprobando en uso real.
