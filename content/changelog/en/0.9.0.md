You can now dictate into the terminal and the editor, start a session from an issue and finish on it, and let agents read the project through Persisty itself. The editor gained a Markdown preview, sticky scroll and a minimap.

### Voice dictation

![In the terminal, ⌘⇧D starts dictation: the mascot picks up a microphone and, on the second press, the spoken sentence appears typed at the Claude Code prompt.](/changelog/0.9.0/voz.mp4)

- In **Settings › Voice** (off by default): **⌘⇧D** (Command + Shift + D; Ctrl + Shift + D on Windows and Linux) starts listening and, pressed again, types what you said into the terminal or editor in focus, without pressing Enter.
- Everything runs on your computer. The voice model (640 MB) is only downloaded when you ask, shows up in **Settings › Privacy & network** and can be deleted.
- Spoken numbers become digits, some programming terms become symbols (main.rs, --release, /compact), and you can add your own replacements.
- While you dictate, the mascot of the terminal that will receive the text picks up a microphone.

### Tasks and issues

- **Settings › Integrations** gained Linear, Jira Cloud and ClickUp, each with step-by-step instructions to connect. GitHub issues come with the GitHub account you already connected.
- Each project picks its service in **Project settings › Tasks**.
- **Start from an issue**, in New session: the session takes the issue's name, its branch in the session's own folder and a request to the agent with the title, link and description, which you can edit before creating it.

![In New session, Choose issue lists the Linear issues; the chosen one names the session and writes the request to the agent, and the session opens working on it, with the issue in its bar.](/changelog/0.9.0/issue.mp4)

- **Finish on the issue**: the session's bar shows the issue key and a Finish button, with a suggested comment and the new status. Nothing is written to the service until you send it.

![In the bar of a session that finished issue ENG-123, Finish brings a suggested comment and the new status, In Review, and sends both to Linear.](/changelog/0.9.0/concluir.mp4)

### Agents that read Persisty

- In **Settings › Agents** (off by default): Claude Code sessions started or restarted with it on get tools that read the project, its other sessions and the output of its tasks, without you copying anything from one terminal to another.
- **Check installation** tests the connection for real.

### Editor

- **Markdown preview**: the eye button on a `.md` file's bar shows the formatted text, unsaved edits included. **⌘⇧V** switches between the preview and the code, and **Settings › Editor** can open `.md` files straight in it.

![In a .md file open in the editor, a new item is typed into the list and ⌘⇧V shows the formatted text, with the table, the task list and the unsaved edit.](/changelog/0.9.0/markdown.mp4)

- **Sticky scroll**: the start of the function, class or heading you are in stays at the top of the editor, and a click takes you there.

![Scrolling a TypeScript file keeps the class, the method and the blocks you are in pinned at the top, with the minimap alongside; a click on one goes there.](/changelog/0.9.0/contexto-fixo.mp4)

- **Minimap**, as characters or blocks, with adjustable scale and visibility.

### Changed on the Mac

- Programs running in sessions no longer use the privacy permissions given to Persisty (microphone, folders, accessibility): macOS decides for them and asks when it needs to. The first session in a protected folder (Documents, Desktop, Downloads) may ask for access to it.
- Until the Mac restarts, sessions, new ones included, keep using Persisty's permissions.

### Fixed

- Each session's 5-hour and 7-day usage is that of the account it runs on, live, like Claude Code's `/usage`. Spend and context are those of the current conversation.
- With **Reduce motion** on, the editor's line numbers line up with the code, and search takes you to the right line.
- An update that stops half-way through the download gives up after 30 seconds without receiving anything, instead of staying on "Downloading…". **Privacy & network** shows every server the check and the download go through.
- On Linux, the `.deb` package installs alongside the programs the system already has. Before, with a common package installed, it would not install.

Windows and Linux are still a preview: unsigned and not yet tested on real machines.
