---
title: Nothing to install separately, and builds for Windows and Linux
version: 0.6.0
date: 2026-10-21
---

- Everything Persisty needs now ships **inside the app**. You no longer need to install anything separately.
- On Windows, agents work without a POSIX shell: Claude Code's hooks call a native executable.
- There is an installer for Windows, and `.deb` and AppImage packages are set up for Linux. Neither has been tested on real machines yet, and both will ship as a preview.
- Fixed: agent events could be lost when a line was read while it was still being written.
