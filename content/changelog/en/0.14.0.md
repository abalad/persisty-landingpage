---
title: The editor understands your code and moves through it
version: 0.14.0
date: 2026-11-17
---

The editor now uses the language server to find usages, rename, fix, refactor and format, gets WebStorm's navigation, and keeps the versions of every file. The keys below are the default (WebStorm) keymap on the Mac; on Windows and Linux, Command becomes Control and Option becomes Alt, unless the line says otherwise. Everything is also in the command palette and in Settings › Shortcuts.

### Added

- **A bottom panel in the editor**, with Usages and Problems tabs and an adjustable height. Problems lists errors and warnings by file, and clicking the count in the status bar opens it. In the code, Command + 3 opens Usages and Command + 6 opens Problems (Alt + 3 and Alt + 6 on Windows and Linux).
- **Find usages** (Option + F7) lists where a name is used, by file and line. Command + Option + Down and Up walk through them.
- **Go to implementation** (Command + Option + B) **and to type** (Control + Shift + B) jump straight there, or list the targets in Usages when there are several.
- **Highlight usages in the file** (Command + Shift + F7) marks every occurrence of the name at the cursor, and the status bar counts them.
- **Rename across all files** (Shift + F6). Open tabs get the change with undo, and a notice says how many files changed and which were left out.
- **Quick fixes** (Option + Enter). A list next to the cursor shows what the server offers there, and Enter applies it in one undo step.
- **Extract and inline.** Extract variable (Command + Option + V), constant (C), function (M), inline (N) and "Refactor…", with everything the server offers at the cursor.
- **Format** (Command + Option + L) the file or the selection, **and optimize imports** (Command + Option + O).
- **Replace in files**, in the Search panel. Each line shows old and new side by side. Replace in one file, drop a line from the list, or replace everything. A file that changed after the search is left out and named in the notice.
- **Local history.** The editor keeps the versions of every text file in the folder, on this computer only: on save, when a file changes outside the app, and before rename, move, replace, delete or discard.
  - Local History › Show History, in the tree and on the tab, shows who changed what and when, with the diff.
  - Revert a whole version or just one hunk, and on a folder, recover a deleted file.
  - How long and how much space it keeps are in Settings › Editor › Local history.
- **Recent files** (Command + E in the code) lists the session's last 50 files, even from closed tabs. Press it again to show only the edited ones.
- **Recent locations** (Command + Shift + E in the code) lists where the cursor has been and what was edited, with 3 lines of code from each place.
- **Last edit location** (Command + Shift + Backspace). Press it again for the edit before.
- **File structure** (Command + F12) opens the file's symbols in an indented list, already on the symbol at the cursor.
- **Go to symbol** (Command + Option + Shift + N) **and to class** (Command + N) search the whole project as you type.
- **Next and previous method.** On the Mac, Control + Down and Up, and also Control + Shift + arrow, because Mission Control uses the first. On Windows and Linux, Alt + arrow.
- **Show the file in the tree** (Option + F1), also in the tab menu.
- **Quick definition** (Command + Shift + I) shows the declaration in a popup next to the cursor, without leaving your place.
- **Bookmarks for lines, files and folders**, per project.
  - F11 marks the cursor's line, and a mark in the gutter follows your edits.
  - Shift + F11 opens the list.
  - Files and folders go in from the Bookmarks submenu in the tree and on the tab.
- **Search everywhere.** Press Shift twice to search files, symbols and actions in one list. Typing capital letters never opens it.
- **Column selection** (Command + Shift + 8; Alt + Shift + Insert on Windows and Linux). Shift + arrows and dragging with the mouse make a rectangle, and typing writes on every line.
- **Clone caret.** Press Option twice (Control on Windows and Linux), hold it, and use the Up or Down arrow.

### Changed

- **The session header now only shows the session's information.** Rename and close are on the session's tab, and the history moved to the right toolbar, above Details. To end the agent, exit it in the terminal or close the session's tab.
- **Some keys change meaning only inside the code**, as in WebStorm: Command + E, Command + Shift + E, Command + N and Command + Shift + I. Outside the code they keep doing what they did in the app.
- **In the WebStorm macOS keymap,** F3 toggles a bookmark, and find next is Command + G, as in WebStorm.

Actions that rely on the language server need a server running for the file's language. Without one, the key goes on to the app.
