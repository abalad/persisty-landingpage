title: Files in the tree, like in an IDE
version: 0.12.0

---

The editor's file tree now does what you expect from an IDE: rename, move, copy, paste and delete, from the keyboard, the menu and by dragging.

### Added

- **Rename files and folders from the tree and from a tab (Shift + F6).** The name is edited right in the row, and open tabs follow the file with their unsaved text and undo.
- **Move and copy to another folder (F6 and F5).** A list with search picks the folder. When copying a single item, you can give it a new name right there. All three are also in the Refactor submenu.
- **Drag in the tree to move.** Just hold a file or folder and drop it on another folder. With Option (Alt on Windows and Linux), it copies.
- **Cut, copy and paste files and folders in the tree** (Command + X, C and V on the Mac; Control + X, C and V on Windows and Linux). You can also paste what you copied in the Finder, File Explorer on Windows or the Linux file manager, and the other way round.
- **Delete to the Trash, with Undo.** Delete or Command + Backspace on the Mac, and Delete on Windows and Linux. It always asks first, and for 10 seconds you can undo from the notice or with Command + Z (Control + Z on Windows and Linux).
- **One question when a name is taken.** Rename, replace (the old one goes to the Trash) or skip, with "do the same for the next ones". Before replacing a file with unsaved changes, Persisty asks.
- **Big copies show their progress and can be cancelled.** Cancelling leaves nothing half-done at the destination.
- **Change a file's type**, for example a `.env` as Shell, from the tree, a tab or the command palette (Command + K). The choice holds for the project folder and follows the file when it moves.
- **If a move or copy stops midway, what already went stays**, and Persisty says which item failed.

On Windows and Linux, pasting files with the system and Undo after a delete are still being checked in real use.
