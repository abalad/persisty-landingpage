A fix for people using Persisty on Windows.

### Fixed

- **Add workspace** accepts the chosen folder on Windows (`C:\...`): the folder type shows up and the **Add workspace** button turns on. Before, the folder wasn't recognized and you couldn't go on.
- A **New session** in a Windows workspace is created as expected too.
