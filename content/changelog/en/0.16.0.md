This version brings:

- scratch files;
- GitHub Gists straight from the editor;
- a list of your recent copies to paste from;
- Azure DevOps among the task services.

You can also sign in again to a Claude Code account whose login expired, and on Windows the mascot now walks on top of your windows.

### Added

- **Paste from History** (Command + Shift + V in the code with the WebStorm keymaps; Control + Shift + V on Windows and Linux).
  - Opens the list of the last 30 copies and cuts made in the editor.
  - Pick one, or mark several with Shift + arrows or Command + click, and they are all pasted at once. One undo takes them all out.
  - The history lives only in memory and is gone when you close the app.
  - Outside the code, the key is still the Markdown preview.
- **Scratch files.** Pick the language and the file opens in a tab, outside the project and saved on its own.
  - To create one, use New › Scratch file in the tree, or the keys:
    - Control + Shift + N in the WebStorm Classic keymap on the Mac;
    - Command + Shift + N in WebStorm macOS, with the cursor in the code;
    - Control + Alt + Shift + Insert on Windows and Linux.
  - The "Scratches" section, at the bottom of the tree, lists the ones from every project and lets you open, rename and delete them. Whatever you delete goes to the Trash.
- **Create Gist…**, in the tree and tab menus and in the palette: up to 20 files, a scratch file or just the selected code become a GitHub Gist. It is secret by default, or public if you choose. The link is copied and a notice opens the Gist.
  - Before sending, a file that looks like it holds a secret (a .env, a key, a token, a password) asks "Send anyway".
  - The first time, GitHub asks for the gist permission. If you sign in with another GitHub account at that point, nothing is sent, and the notice says which account to use.
  - An account connected with a token that lacks this permission gets an error saying what is missing.
- **Azure DevOps in tasks.**
  - In Integrations, connect your organization with a personal access token. This works for dev.azure.com, for the older visualstudio.com address and for your company's server.
  - Link a project in Project settings › Tasks and start sessions from its work items, as you already can with GitHub, Linear, Jira and ClickUp.
  - When you finish, the comment goes into the item's discussion, and the state moves among the states of its type.

### Fixed

- **AI accounts says why an account's quota is missing,** instead of "Quota unavailable": access expired, sign-in refused, signed out or no network.
  - When the login expired, was refused or is missing, the account gets a "Sign in again" button. It opens Claude Code's own sign-in in the browser for that account, this computer's included, and keeps it in the list.
  - The quota comes back right after. This works on any plan.
- **On Windows, the floating mascot stands and walks on top of your open windows,** as on the Mac, instead of always falling to the bottom of the screen. The "The mascot walks on your windows" setting now shows on Windows too.
- **On Windows without the HOME variable, the app finds this computer's Claude Code account through your user folder.** A session can leave a reserved account again.
- **The Git panel, the Changes tab and the editor no longer hold the git index while they read.** A commit made in the terminal, yours or an agent's, no longer fails with "index.lock exists" because of the app.
- **Moving a statement up or down takes the neighbour's documentation comment along,** also when the statement is very long.
- **Settings › Voice warns when the recorded dictation key is also an action of the keymap or the app,** for example after switching keymaps, and tells you how to record another one. The key never changes on its own.
- **On the Board, the card of a session that asked a question shows its end,** with the question mark, instead of its beginning. The whole question appears when you hover over it.

Azure DevOps is still being checked against a real organization. The mascot and the computer's account on Windows are still being checked on real machines.
