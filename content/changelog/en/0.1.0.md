The first version of Persisty for daily use:

- **Projects** with several workspaces, showing each folder's branch and changes.

![Switching between session tabs, workspaces and projects: each folder shows its branch and changes, and each session keeps its terminal history.](/changelog/0.1.0/projetos.mp4)

- **Persistent sessions** in tabs, each with its terminal history.
- **Restore all** after restarting the computer, with a report of what came back, what failed and why. Running it twice does not duplicate sessions.

![After the computer restarts, the project's sessions show as interrupted and one click on Restore brings them all back, with their history.](/changelog/0.1.0/restaurar.mp4)

- **Claude Code** with a session id chosen by Persisty, states from hooks and resume with `--resume` confirmed by Claude Code itself.
- **AI usage**: estimated spend by session, project, model and day, always labelled as an estimate.

![The AI usage page shows the project's estimated spend by period, session and model and, under All projects, by project.](/changelog/0.1.0/uso.mp4)
