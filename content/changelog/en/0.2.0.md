- **Session side panel** (⌘\\): Changes, Code, Search, Notes and Details beside the terminal, with a draggable divider.

![Command and backslash open the side panel next to the terminal and the divider widens it; Changes shows a file's diff and Search looks across all files.](/changelog/0.2.0/painel.mp4)

- **Editor**: a tree of the session's folder, tabs, ⌘S, a warning when the file changes on disk, syntax highlighting per language, ⌘P, ⌘⇧F and git marks in the gutter.
- **Changes**: stage and unstage file by file, commit with ⌘↵, "Commit and push", a diff per file and a history of what has not been pushed.

![In Changes, a file's diff, the button that stages it and a commit made with Command and Enter, which shows in the history as not pushed yet.](/changelog/0.2.0/commit.mp4)

- **Branch in the session header**, with search, local and remote branches and "Create branch".

![The branch in the session header opens the list of local and remote branches; typing a new name offers Create branch and the session moves to it.](/changelog/0.2.0/branch.mp4)

- **Command drawer**: each workspace command becomes a tab with its state written out. Stopping sends Ctrl-C and keeps the output.

![Workspace commands run in a drawer below the terminal, one tab each with its state written: dev running and test failed, with its output kept.](/changelog/0.2.0/comandos.mp4)
