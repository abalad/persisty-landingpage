Esta versão traz:

- arquivos de rascunho;
- o Gist do GitHub direto do editor;
- a lista das últimas cópias para colar;
- o Azure DevOps entre os serviços de tarefas.

Também dá para entrar de novo numa conta do Claude Code cujo login venceu, e no Windows o mascote passa a andar em cima das janelas.

### Adicionado

- **Colar do histórico** (Command + Shift + V no código com os mapas do WebStorm; Control + Shift + V no Windows e no Linux).
  - Abre a lista das últimas 30 cópias e recortes feitos no editor.
  - Escolha uma, ou marque várias com Shift + setas ou Command + clique, e todas são coladas de uma vez. Um desfazer tira tudo.
  - O histórico fica só na memória e some ao fechar o app.
  - Fora do código, a tecla continua sendo a da pré-visualização do Markdown.
- **Arquivos de rascunho.** Escolha a linguagem e o arquivo abre numa aba, fora do projeto e gravado sozinho.
  - Para criar um, use Novo › Arquivo de rascunho na árvore, ou as teclas:
    - Control + Shift + N no mapa WebStorm Classic do Mac;
    - Command + Shift + N no WebStorm macOS, com o cursor no código;
    - Control + Alt + Shift + Insert no Windows e no Linux.
  - A seção "Rascunhos", no fim da árvore, lista os de todos os projetos e deixa abrir, renomear e excluir. O que você exclui vai para a Lixeira.
- **Criar Gist…**, nos menus da árvore e da aba e na paleta: até 20 arquivos, um rascunho ou só o trecho selecionado viram um Gist do GitHub. Ele é secreto por padrão, ou público, se você escolher. O link é copiado e um aviso abre o Gist.
  - Antes de enviar, um arquivo que parece ter segredo (um .env, uma chave, um token, uma senha) pede "Enviar mesmo assim".
  - Na primeira vez, o GitHub pede a permissão gist. Se nessa hora você entrar com outra conta do GitHub, nada é enviado, e o aviso diz com qual conta entrar.
  - Uma conta conectada por token sem essa permissão recebe um erro que diz o que falta.
- **Azure DevOps nas tarefas.**
  - Em Integrações, conecte a organização com um token pessoal. Vale para dev.azure.com, para o endereço antigo visualstudio.com e para o servidor da empresa.
  - Ligue um projeto em Ajustes do projeto › Tarefas e comece sessões a partir dos work items, como já dá com GitHub, Linear, Jira e ClickUp.
  - Ao concluir, o comentário entra na discussão do item, e o estado muda entre os do tipo dele.

### Corrigido

- **Contas de IA diz por que a quota de uma conta não aparece,** no lugar de "Quota indisponível": acesso vencido, login recusado, sem login ou sem rede.
  - Quando o login venceu, foi recusado ou não existe, a conta ganha o botão "Entrar de novo". Ele abre no navegador o login do próprio Claude Code para aquela conta, inclusive a deste computador, sem tirá-la da lista.
  - A quota volta logo depois. Vale em qualquer plano.
- **No Windows, o mascote fora do app fica e anda em cima das janelas abertas,** como no Mac, em vez de sempre cair até o chão da tela. O ajuste "O mascote anda sobre as janelas" aparece também no Windows.
- **No Windows sem a variável HOME, o app acha a conta do Claude Code do computador pela pasta do usuário.** Assim, uma sessão consegue sair de uma conta reservada.
- **O painel Git, a aba Alterações e o editor não seguram mais o índice do git enquanto leem.** Um commit feito no terminal, seu ou do agente, não falha mais com "index.lock exists" por causa do app.
- **Mover instrução para cima ou para baixo leva junto o comentário de documentação do vizinho,** também quando a instrução é muito longa.
- **Configurações › Voz avisa quando a tecla de ditado gravada também é uma ação do mapa de teclas ou do app,** por exemplo depois de trocar de mapa, e diz como gravar outra. A tecla nunca muda sozinha.
- **No Quadro, o cartão de uma sessão que fez uma pergunta mostra o fim dela,** com a interrogação, em vez do começo. A pergunta inteira aparece ao parar o ponteiro em cima.
