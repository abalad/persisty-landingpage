---
title: Nada para instalar à parte e builds para Windows e Linux
version: 0.6.0
date: 2026-10-21
---

- Tudo de que o Persisty precisa agora vai **dentro do app**. Não é mais preciso instalar nada à parte.
- No Windows, os agentes funcionam sem shell POSIX: os hooks do Claude Code chamam um executável nativo.
- Existe um instalador para Windows e pacotes `.deb` e AppImage configurados para Linux. Os dois ainda não foram testados em máquinas reais e vão sair como prévia.
- Corrigido: eventos dos agentes podiam se perder quando uma linha era lida no meio da escrita.
